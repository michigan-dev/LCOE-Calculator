How this is calculated

Levelized cost of electricity spreads all lifetime costs over all lifetime output. This tool uses the standard simplified, pre-tax form:

CRF  = r(1+r)^n / ((1+r)^n - 1)

LCOE = (Capital x CRF + Fixed O&M) / (8.76 x Capacity factor)
       + Variable O&M + Fuel
  • r is the discount rate (WACC) as a decimal; n is the project lifetime in years. If r = 0, CRF = 1/n.
  • Capital and fixed O&M are in $/kW and $/kW-year, so one kW produces 8.76 × capacity factor MWh per year (8,760 hours ÷ 1,000).
  • Variable O&M and fuel are already in $/MWh and are added directly.
  • Not modelled: taxes, incentives, inflation, degradation, financing structure, transmission, or the value of firm vs. variable power.
